Card push notifications can now auto-switch folder and interval by time of day

- Set 9am-6pm to English words and 6pm-11pm to Hebrew, and both the folder and the interval switch on their own
- Add up to 5 time ranges, including ones crossing midnight like 10pm-2am
- Leave the interval empty to keep the default interval
- When ranges overlap, the list shows the hours each one actually covers
- If a range's folder is deleted or empty, the default folder is used instead
